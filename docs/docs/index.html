JobFoundry Documentation

JobFoundry is a local-first, privacy-respecting pipeline designed to find jobs across 84+ platforms, deduplicate cross-postings, score candidate fit with local LLMs, and compile tailored ATS-compliant resumes.

◈Architectural Invariant

The JobFoundry server never performs outbound job-board scraping. All scraping and job-board HTTP requests originate from the user's browser extension using existing authenticated sessions.
