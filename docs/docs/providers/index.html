Supported Job Boards & ATS Providers

JobFoundry supports over 84 job boards, Applicant Tracking Systems (ATS), and career portals. All extractions are executed locally within your browser using DOM scrapers and JSON-LD structured schemas.

◈Request a New Provider

Don't see a job board or enterprise ATS you frequent? Submit a provider request via our Feedback Portal or file an issue on GitHub with a sample job posting URL.

How Providers Work Under the Hood

Each provider extractor lives in extension/src/extractors/ and exports a standard interface:

// Interface: ProviderExtractor
interface ProviderExtractor {
  matches(url: URL): boolean;
  extract(document: Document): ExtractedJobPayload | null;
}

When you open a job listing, the extension checks URL match patterns. If a known provider matches, it parses the document immediately. If an unrecognized site contains standard schema.org/JobPosting JSON-LD, the generic fallback extractor automatically captures it.

Contributing a New Extractor

Adding support for a new job board takes fewer than 30 lines of code. Read our Contributing Guide to submit a pull request!

Architectural Invariant

The JobFoundry server never performs outbound job-board scraping. All scraping and job-board HTTP requests originate from the user's browser extension.
