Core Architectural Invariant (Zero Server Scraping)

The JobFoundry server never performs outbound job-board scraping. All discovery and extraction happens safely within your local browser extension session. Your self-hosted server receives clean, normalized JSON and communicates only with your chosen LLM endpoint and local PDF compiler.

Capabilities

Engineered for Complete Job Search Autonomy

Built from the ground up for speed, privacy, and precision fit.

84+ Job Board Providers

Passive DOM extraction and active provider sync across Greenhouse, Lever, Ashby, Workday, LinkedIn, Indeed, Glassdoor, Naukri, and 76+ custom ATS engines.

SimHash Dedup Engine

Two-tier deduplication: fast 64-bit SimHash hamming distance filtering in the browser extension and authoritative SQLite upsert in the Ingest backend.

LiteLLM AI Fit Scorer

Structured Python fit evaluation returning calibrated match score (0-100), matching qualifications, missing criteria, and tailored positioning strategy.

Resume Tailoring Bridge

Re-writes resume experience bullets to directly emphasize target job requirements while preserving truthful career history. Multi-theme PDF & ATS plaintext outputs.

Real-Time Kanban Dashboard

React 19 SPA with live job feed, fit score badges, status columns (New, Saved, Applied, Interview, Offer, Rejected), diff inspector, and 1-click downloads.

Multi-User Isolation

Multi-tenant SQLite schema with Argon2 password hashing, JWT and API-key authentication, isolated JSON Resume profiles, and user-scoped worker scoring.

FAQ

Frequently Asked Questions

How is JobFoundry different from cloud job scrapers? ↓
JobFoundry is 100% local-first. Most scrapers get IP-blocked by Cloudflare/DataDome because they scrape from remote datacenter IPs. JobFoundry extracts listings from your own browser extension during your legitimate web browsing, making extraction completely resilient and unblockable.
Can I use local LLMs like Ollama? ↓
Yes! JobFoundry uses LiteLLM under the hood. You can configure any local model (e.g. ollama/llama3.1, vllm/mistral) or commercial endpoint (OpenAI, Anthropic, DeepSeek) simply by setting the LLM_MODEL environment variable in your .env file.
What formats are supported for resume generation? ↓
JobFoundry supports standard JSON Resume v1.0.0 as the master schema, and exports high-quality multi-theme PDFs (Modern, Minimal, Executive) as well as raw ATS-optimized clean plaintext ready for copy-pasting.
