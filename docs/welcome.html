Quickstart Guide

Get Up & Running in Minutes

Follow these 5 steps to start your local JobFoundry instance, connect your browser extension, and unlock automated AI fit scoring & ATS tailoring.

1
Configure Environment & Launch Backend Stack

Clone the repository, configure your .env file (with your LiteLLM or OpenAI keys), and spin up the complete orchestration with Docker Compose:

cp .env.example .env
docker compose up --build -d

Or run locally in development mode:

npm test  # Runs full monorepo & E2E validation
2
Build & Load Browser Extension

Build the Chrome MV3 or Firefox MV2/MV3 distribution:

npm --workspace=extension run build:release
  • Chrome / Brave / Edge: Open chrome://extensions, enable Developer mode, and click Load unpacked → select extension/dist/chrome/.
  • Firefox: Open about:debugging#/runtime/this-firefox and load extension/dist/firefox/manifest.json.
3
Pair Extension with Ingest API

Click the JobFoundry icon in your browser toolbar to open the popup. Enter your Ingest Server URL (default: http://localhost:8080) and your user API key.

The extension popup will display a green checkmark indicating successful pairing with your local SQLite database.

4
Upload Your Master JSON Resume

Open the Web Dashboard at http://localhost:5173. Navigate to the Resume Manager tab and paste or upload your standard JSON Resume.

This resume serves as your canonical truth source for AI fit scoring and ATS bullet point generation.

5
Ingest Jobs & Tailor Applications

Browse any job board (LinkedIn, Indeed, Greenhouse, Lever, Ashby, etc.). The extension passively captures listings you view, or you can trigger an active sync across 84+ supported ATS endpoints.

Head to your dashboard to inspect fit scores (e.g. 92/100), missing skills, generated cover letters, and download your tailored multi-theme PDF or ATS plaintext resume with 1-click!
