Privacy Policy & Architectural Invariants

Last updated: August 19, 2026
Privacy-First & Self-Hosted: JobFoundry is fully open-source and local-first. We do not operate remote tracking servers, do not collect personal usage analytics, and never resell job search data or resumes.
Core Architectural Invariant (Non-Negotiable)

The JobFoundry server never performs outbound job-board scraping. All job board discovery and extraction happens exclusively within your local browser extension on your own device. The self-hosted server receives only what you ingest, and its only outbound network connections are to your configured LLM provider (e.g. LiteLLM, Ollama, OpenAI, Anthropic) and the local PDF generation engine.

1. Where Your Data Lives

All data generated during your job search remains entirely under your control:

  • Job Postings: Stored in your local or self-hosted SQLite database (server/ingest/data/jobfoundry.db) managed by your own JobFoundry instance.
  • Resumes & Career History: Your Master JSON Resume and generated tailored versions are stored securely in your private database and file artifacts directory.
  • Browser Extension Storage: Temporary bookmarks, active provider sync caches, and local server pairing tokens are stored exclusively in your browser's private chrome.storage.local or browser.storage.local.

2. AI & Fit Scoring Privacy

JobFoundry uses LLMs to perform fit scoring, analyze missing requirements, and generate tailored resume bullet points:

  • User-Provided API Keys: You provide your own API keys directly to your self-hosted instance. Keys never leave your server.
  • Local LLM Support: You can configure 100% offline local inference via Ollama or vLLM so that zero data leaves your local network.
  • No Training on Your Data: Standard enterprise API endpoints configured via LiteLLM (such as OpenAI, Anthropic, or DeepSeek API) do not train on API requests by default.

3. Multi-User Authentication & Isolation

When running in multi-user mode:

  • Passworld hashes are encrypted using modern Argon2/scrypt key derivation.
  • User workspaces, resumes, job feeds, and fit scores are cryptographically isolated and tenancy-enforced via foreign key constraints.
  • API keys and JWTs are scoped strictly to the authenticated user.

4. Telemetry & Analytics Overview

JobFoundry Software & Extension: Contains zero advertising SDKs, zero behavioral trackers (such as Google Analytics or Segment), and zero remote telemetry beacons. All job scraping and resumes remain on your device.

Documentation Website (JobFoundry.covai.org): Our public documentation pages use privacy-friendly, zero-cookie web analytics and session recording services with strict text masking to measure page views, popular guides, and referrer sources. No resume data or search inputs are ever captured.

5. Open Source Auditability

The entire codebase of JobFoundry (Browser Extension, Ingest Server, Scorer Worker, and Web Dashboard) is open source under the GNU Affero General Public License v3.0 (AGPL-3.0). You can inspect every line of code on GitHub.
