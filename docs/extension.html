Installing on Chrome, Brave, Edge & Arc

  1. Download jobfoundry-extension-*-chrome.zip from GitHub Releases and extract it to a local directory.
  2. Open chrome://extensions (or brave://extensions / edge://extensions) in your browser.
  3. Enable the Developer mode toggle located in the top-right corner.
  4. Click the Load unpacked button in the top-left corner and select the extracted extension directory.

Installing on Mozilla Firefox

  1. Download jobfoundry-extension-*-firefox.zip from GitHub Releases.
  2. Open a new tab and navigate to about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on... and select the downloaded .zip file (or extract and select manifest.json).
Zero-Configuration Setup

⚡ 1-Click Dashboard Auto-Connect

No need to copy and paste API keys manually. Once your JobFoundry dashboard is open (e.g., http://localhost:5173), simply open the extension popup and click Auto-Connect. The extension automatically detects your session, pairs with your ingest server, and synchronizes your title filters.
